Measure, classify, route, apply, re-measure, repeat. The loop stops when every group meets, when no lever is left, or at the iteration cap. Pick a run and read down. Each step shows the evidence it decided on, so a routing decision you disagree with can be argued with rather than guessed at.

Six transforms, proposed by an LLM against a real timing report and frozen in git before any check ran. The declared transform type selects the proof obligation; nothing here is free-text Verilog that a human then vetted. Two are wrong.

Every RTL benchmark we could find grades a design or a testbench. SlackBench grades the checker. Eight cases, ground truth declared before any checker ran, each built to defeat one abstraction. Our own checker is in the table and it is wrong twice.

recovered the ground truth wrong CANNOT: the question is not expressible by this method excluded, would score the tool that established the truth

CANNOT is a first-class answer, not a failure. Combinational equivalence checking matches state elements one for one, so it cannot compare designs whose flop counts differ. That is not a bug in cec; it is the point of the case. A checker that answers REJECT to everything gets every trap right, which is why a single score per checker is a misuse of this table.

Every equivalence checker on this page answers a question about two netlists. Here is a way to close a timing group that no equivalence checker can ever catch, because the design does not change at all.

One line of SDC moves clk_e from VIOLATED to MET, worth +5.179 ns, on a byte-identical netlist. clk_a and clk_b do not move. Every equivalence checker correctly calls these two designs equivalent, because they are the same file.

This is why the gate has a G0: the SDC is fingerprinted by SHA-256 and its timing exceptions are counted before any measurement is trusted. It is the one check in this project that formal methods cannot supply.
